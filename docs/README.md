Current project focus:

- simple RV32I CPU
- ECC and TMR fault tolerance
- AXI4-Lite SoC integration
- UART, timer/watchdog, and health telemetry
- FPGA bring-up on Arty A7

Future work:

- DMA
- one FIR accelerator
- FPGA timing/resource reports
- simple benchmark results
